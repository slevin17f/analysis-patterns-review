# 决策规则速查 — Analysis Patterns: Reusable Object Models

| 能力 | 一句话规则 |
|---|---|
| 组织责任与岗位 | 问清谁对谁承担哪一类责任，再决定是否需要岗位和规则层。 |
| 观察、双时间与更正 | 分开记录事实适用于何时、何时获知，以及哪条证据推翻了旧判断。 |
| 分部指标与计算口径 | 比较或汇总前先对齐分部、时期、单位和计算协议。 |
| 标识体系与重复对象 | 先在标识体系内解析编号，再用独立证据裁定记录同一性。 |
| 账户、分录与入账规则 | 为同口径转移建立守恒分录，把派生账项连回输入与规则。 |
| 计划、执行与资源 | 分开保存拟做、实做、资源预订和消耗，逐个对照偏差。 |
| 交易组合与市场情景 | 固定成交条件，在各情景中独立选择、追溯行情并重算。 |
| 产品、合约与行权事件 | 从权利义务和事件响应选择子类或组合，并区分销售产品与内部合约。 |
| 包的接口与可见性 | 按客户需要的可见接口划分包，模拟引入新子类型时的依赖变化。 |
| 分层与应用门面 | 让展示处理格式、门面编排用例、领域对象维护跨入口规则。 |
| 类型模型的实现契约 | 将类型图展开为读写、创建和销毁契约，核对每条关联的不变量。 |
| 带属性、键和历史的关联 | 由实际查询决定是否要关联对象、键或有效区间，再验证端点。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
