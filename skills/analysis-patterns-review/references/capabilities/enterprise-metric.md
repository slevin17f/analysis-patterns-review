# 分部指标与计算口径

## R · 原书依据

§4.1–4.5，图 4.2。比较或汇总前先对齐分部、时期、单位和计算协议。

## I · 如何选择

比较或汇总前先对齐分部、时期、单位和计算协议。
- 每维选一个元素组成分部，全体用顶层元素；把取值和计算写成协议；分清因果、比较和维度组合；区间随条件变化时使用范围函数。

## A1 · 原书建模示例

给企业分部增加销售渠道（§4.1，第 60–61 页，图 4.2）。某分部由东北地区、产品 11-10 和政府客户构成；增加渠道这个维度后，原分部涵盖所有渠道。在渠道维度选择顶层元素 all，原分部的覆盖范围保持一致。

## A2 · 何时调用

指标 / 汇总 / 分母的建模或评审。语言线索包括 指标 汇总 分母 阈值 企业分部。相关但输出不同的任务见「观察、双时间与更正」。

## E · 执行与验收

输入需要业务维度及层级、指标来源或计算口径。

1. 每维选一个元素组成分部，全体用顶层元素。
2. 把取值和计算写成协议。
3. 分清因果、比较和维度组合。
4. 区间随条件变化时使用范围函数。

按项目涉及的分支检查：

- 明确焦点事件及其维度路径，按指标定义组合子分部；发生额可按月相加，年初至今累计值逐月相加会重计。
- 对一个衍生指标逆向追踪到具体源观察和计算方法；只保留指标名称无法解释来源。
- 两个输入属于同一现象类型，分清实际、预算等角色；相对偏差的基准需有定义。 计算规则：绝对偏差=x−y；相对偏差=(x−y)/y。前提：y=0 时原文公式无定义。
- 对每个阈值测试下方、等于及上方；相同观察因上下文而采用不同区间时，将其作为范围函数的输入。

输出应包含分部坐标、指标协议与比较口径。
给两组各自的分子和分母：汇总比率用合并后分子除以合并后分母；检查样本重叠、零分母和混合期间。

## B · 反例与判停

- 把月末年初至今累计值相加。月度累计互相包含；沿时间维相加要求各期只含本期贡献。（§4.1，书页 65）
- 缺少维度层级或可汇总规则时保留未知。
