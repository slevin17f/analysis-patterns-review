# 标识体系与重复对象

## R · 原书依据

§5.1–5.4，pp.86–93。先在标识体系内解析编号，再用独立证据裁定记录同一性。

## I · 如何选择

先在标识体系内解析编号，再用独立证据裁定记录同一性。
- 用体系加标识寻找对象；若为同一对象，按改写引用能力与可撤回性选择迁移并删除、替代链接或外观与本体；等价有争议时保存其作用语境。

## A1 · 原书建模示例

同一名患者出现两份档案（§5.3，第 90–92 页）。住院患者另有一份门诊档案。若合并决定将来可能被推翻，用一个 essence 关联两个 appearance，可保留两份原记录。若后来证实是两个不同的 John Smith，移除共同 essence 的连接即可区分两份身份记录。

## A2 · 何时调用

同名 / 重档 / 外部编号的建模或评审。语言线索包括 同名 重档 外部编号 身份合并 identifier。相关但输出不同的任务见「组织责任与岗位」。

## E · 执行与验收

输入需要名称、识别体系、重复证据与引用方。

1. 用体系加标识寻找对象。
2. 若为同一对象，按改写引用能力与可撤回性选择迁移并删除、替代链接或外观与本体。
3. 等价有争议时保存其作用语境。

按项目涉及的分支检查：

- 分别测试同体系同串指向两个对象、两体系共用一个串、同对象在同体系有两个串；最后一种由别名政策决定。
- 评审合并前保留了哪些来源，能否拆回并解释合并期间新录的事实；确认业务是否要求撤销。

输出应包含引用处置表和等价判断。
给两个体系分别发号 101。验证两号可并存，已确认同一后旧入口仍可定位各自病历。

## B · 反例与判停

- 复制并删除重复对象后留下悬空引用。重定向标识符只解决按标识符查找；内部直接引用仍可能指向旧对象。（§5.3.1，书页 90）
- 相似名称不足以证明同一性。
